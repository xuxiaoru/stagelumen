## Introduction

When specifying control protocols for a touring rig, there are several options to consider. DMX, Art-Net, and sACN are three popular protocols that offer different benefits and trade-offs. In this article, we'll compare these protocols and help you decide which one is best for your needs.

## DMX

DMX is a widely used protocol that has been the industry standard for many years. It's a point-to-point protocol that uses a single cable to connect devices, making it easy to set up and troubleshoot. DMX is also a relatively low-bandwidth protocol, which makes it suitable for applications with a small number of devices.

One of the advantages of DMX is its simplicity. It's easy to learn and use, and many lighting consoles and devices support DMX out of the box. However, DMX has some limitations. It's not suitable for applications with a large number of devices, as it can become cumbersome to set up and manage. Additionally, DMX is not as scalable as other protocols, making it less suitable for large-scale productions.

## Art-Net

Art-Net is a protocol that's similar to DMX, but it's designed to be more scalable and flexible. It uses a network-based approach, which allows multiple devices to be connected to a single network. Art-Net is also a low-bandwidth protocol, making it suitable for applications with a small number of devices.

One of the advantages of Art-Net is its ability to handle a large number of devices. It's designed to be more scalable than DMX, making it suitable for large-scale productions. However, Art-Net requires a network infrastructure, which can add complexity to the setup process. Additionally, Art-Net is not as widely supported as DMX, which can make it more difficult to find compatible devices.

## sACN

sACN (Streaming ACN) is a protocol that's designed to be more flexible and scalable than DMX and Art-Net. It uses a network-based approach, which allows multiple devices to be connected to a single network. sACN is also a low-bandwidth protocol, making it suitable for applications with a small number of devices.

One of the advantages of sACN is its ability to handle a large number of devices. It's designed to be more scalable than DMX and Art-Net, making it suitable for large-scale productions. Additionally, sACN is a more modern protocol than DMX and Art-Net, which makes it more compatible with newer devices.

## Conclusion

When choosing a control protocol for a touring rig, it's essential to consider the specific needs of your production. If you have a small number of devices (10 or fewer DMX channels), DMX or Art-Net may be a good choice. However, if you have a large number of devices or require a more scalable solution, sACN may be a better option.

## Next Steps

If you're planning a touring rig, consider specifying DMX or Art-Net for a small number of devices. If you require a more scalable solution, consider specifying sACN. Be sure to consult with your lighting designer and technical team to determine the best protocol for your specific needs.
