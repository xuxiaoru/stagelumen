# How to Set Up DMX Lighting for a Small Venue

Setting up a DMX lighting rig for the first time can feel intimidating — cables, addresses, universes, controllers. This guide walks you through the whole process in 30 minutes.

## 1. Count Your Fixtures and Channels

Before you buy anything, calculate total channels:

| Fixture | Channels | Quantity | Subtotal |
|---------|----------|----------|----------|
| Moving head (16 CH) | 16 | 4 | 64 |
| LED PAR (8 CH) | 8 | 8 | 64 |
| Laser (10 CH) | 10 | 1 | 10 |
| **Total** | — | **13** | **138** |

A 192-channel console (like the **SL-Mini192**) covers this with room to grow.

## 2. Choose a Controller

For small venues under 200 channels, an entry-level console is plenty. Look for:
- Single DMX universe (512 channels)
- Built-in fixture library (10,000+ profiles)
- At least 10 manual faders
- USB backup

## 3. Address Your Fixtures

Each fixture needs a unique DMX address (1–512). Set via the menu display or DIP switches on the back. Most modern fixtures auto-detect if connected to a controller.

## 4. Run Cables

Use **3-pin XLR** cables (5-pin for pro touring). Run a **daisy-chain**: controller → fixture 1 → fixture 2 → fixture 3. Max 32 fixtures per run. Use a **DMX terminator** (120Ω) at the end.

## 5. Patch in the Controller

Tell the console: "Universe 1, DMX address 1, this is fixture X." Most consoles auto-patch from the fixture library.

## 6. Program Your Show

Start with:
- Static scenes (warm wash, blue wash, blackout)
- Sound-active mode for dance floor
- Chase patterns for energy moments
- A grand-master fader for emergencies

## Common Mistakes to Avoid

- ❌ Using microphone cables instead of DMX cables (impedance mismatch)
- ❌ Two fixtures with the same address (they move in sync = bad)
- ❌ No terminator at the end of the run (signal reflection = flicker)
- ❌ Skipping the user manual (every fixture has quirks)

## Next Steps

Once your basic rig is running, add:
- A haze machine (you'll never go back)
- Wireless DMX for clean cable runs
- A second universe for moving lights
