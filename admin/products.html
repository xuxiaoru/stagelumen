Product Importer

1. Paste CSV

First row is the header. Only model is required — it is the match key, so an existing SKU gets updated and a new one gets created. Column names are flexible (Model, SKU, Item No. all work; spaces and case are ignored). Use ; to separate multiple values in images, features, applications, and to separate specs as Label: Value.

2. Product images (optional)

Name each file after its SKU — SL-B150.jpg — and it is wired to that product automatically. Files are committed to assets/images/products/. Keep batches small (about 12 files, under 2 MB each) — the whole batch travels in one request. For a large catalogue, put image URLs in the CSV image column instead.

Click to choose images, or drop them here

3. Submit

Writes a branch and opens a pull request. Nothing reaches the live site until you merge on GitHub.

Needs the admin token (stored in this browser after first use).
